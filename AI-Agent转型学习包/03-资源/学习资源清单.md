## 二、必读文章（少而精）

| 资源 | 为什么读 |
|---|---|
| ⭐️ **ReAct 论文**（arXiv:2210.03629） | Agent 的起点。读完你就明白所有框架在做什么 |
| ⭐️ **Attention Is All You Need**（arXiv:1706.03762） | Transformer 原论文。不用全懂，但要知道 QKV 是什么 |
| ⭐️ **Lost in the Middle**（arXiv:2307.03172） | 解释了为什么长上下文不可靠 —— RAG 存在的理由 |
| ⭐️ **RAG 原始论文**（arXiv:2005.11401） | 检索增强的原始定义 |
| 👍 **Self-RAG**（arXiv:2310.11511） | 让模型自己决定要不要检索，RAG-as-a-Tool 的理论源头 |
| 👍 **Reflexion**（arXiv:2303.11366） | 让 Agent 从失败中反思重试 |
| 👍 **Tree of Thoughts**（arXiv:2305.10601） | 多路径规划的代表思路 |
| 👍 **Anthropic: Building effective agents** | 工程视角讲什么时候该用 Agent、什么时候不该。**非常务实** |
| 👍 **Prompt Caching** 相关资料 | 省钱的杀手锏，生产必用 |

> 💡 **读论文的方法**：先读摘要和结论，看懂"它解决什么问题"和"效果如何"。
> 实验细节不用逐字看。**招聘方更关心你知不知道这个方法解决什么问题，而不是公式。**

## 四、工具与库速查

### 向量数据库 / 检索

| 工具 | 适用场景 | 备注 |
|---|---|---|
| ⭐️ **pgvector** | 已有 Postgres 时首选 | 不用引入新组件，运维成本最低 |
| ⭐️ **Chroma** | 中小规模、快速原型 | 上手最快，本地文件存储 |
| **Milvus / Qdrant** | 大规模（千万级+） | 需要独立部署 |
| **hnswlib** | 想要 ANN 索引但不想要服务 | 嵌入式库，替代全量扫描 |
| **BM25**: `rank_bm25` 或 `jieba`+自实现 | 混合检索的关键词那一路 | 中文必须配 jieba |
| **rerank**: `bge-reranker` | 提升 RAG 精度的性价比之选 | 召回 20 条 → 重排取 5 条 |

### Embedding 模型

| 模型 | 维度 | 特点 |
|---|---|---|
| ⭐️ `text-embedding-v4`（百炼） | 64–2048 可选 | 中文强，有免费额度 |
| `text-embedding-3-small`（OpenAI） | 1536 | 便宜够用 |
| `bge-m3` / `bge-large-zh`（BAAI） | 1024 | 开源可自部署，中文优秀 |

> ⚠️ **铁律**：入库和查询必须用同一个 Embedding 模型。换模型 = 全库重建。

### 评测与可观测

| 工具 | 用途 |
|---|---|
| ⭐️ **Ragas** | RAG 评测标准库（忠实度、答案相关性、上下文精度） |
| **DeepEval** | LLM 应用测试框架，可集成 pytest |
| **LangSmith** | LangChain 官方可观测平台，方便但绑定生态 |
| **Langfuse** | 开源可观测方案，可自部署 |
| **OpenTelemetry** | 通用追踪标准，适合已有观测体系的公司 |
| **tiktoken** | 算 token 数（注意：对非 OpenAI 模型只是估算） |

### 本地模型

| 工具 | 说明 |
|---|---|
| **Ollama** | 本地跑模型最省事，OpenAI 兼容接口。你的机器还没装 |
| **vLLM** | 生产级推理加速，吞吐量比默认实现高很多 |
| **LM Studio** | 带 GUI，适合非命令行用户 |

## 六、本领域"三个月就会过时"的东西

学习时优先掌握**不会过时的部分**：

| 会过时 ❌ | 不会过时 ✅ |
|---|---|
| 具体模型名和价格 | Embedding 的原理和相似度计算 |
| 框架的具体 API 写法 | ReAct 循环的本质 |
| 某个库的版本号 | 切片策略的权衡 |
| Prompt 的具体措辞技巧 | 上下文管理的成本模型 |
| 某个 MCP 服务器 | 工具调用的协议与安全边界 |

**把时间花在右列。** 左列用的时候现查即可。

## 七、本项目已核实的关键时效信息（2026-09）

写这份材料时核实过、且**容易过时**的点，列在这里供你日后对照：

| 项 | 当前状态 |
|---|---|

| MCP 规范 | 2026-07-28 版本，流式传输和认证有更新 |
| OpenAI API 形态 | Responses API 成为推荐入口，Chat Completions 仍可用 |
| 百炼 Embedding 批量上限 | `text-embedding-v4` 单次最多 10 条 |

> 以上每一条都建议你在实际使用时**以官方文档为准**重新核实一次。
